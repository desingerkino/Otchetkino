# Реквизит — финансовый отчёт (iPhone + Mac)

Одно приложение на SwiftUI для iPhone и Mac: подотчётные деньги художника по реквизиту, чеки с фото и распознаванием, остаток,
сцены и категории, синхронизация через iCloud, отчёты в Excel (с фотографиями внутри файла) и PDF.

## Что умеет

- **Проекты и деньги.** Выдача, дополнительные выдачи, возвраты. Остаток = выдано − потрачено − возвращено; перерасход подсвечивается.
- **Покупки и чеки.** Автоматическая сквозная нумерация чеков внутри проекта (№001, №002…). Несколько позиций в одном чеке с общим номером,
  у каждой позиции своя категория, сцены (несколько сразу), назначение и фото товара. Покупки без чека. Несколько фото одного чека,
  замена и удаление фото. Оригиналы фото хранятся без перекодирования (HEIC/JPEG как есть).
- **Распознавание (Apple Vision, на устройстве, без интернета).** Дата, магазин, позиции, итог. Длинные термочеки режутся на полосы.
  Предобработка фото (выравнивание документа, контраст, шумоподавление, повороты на 90°), поля с низкой уверенностью
  (дата, сумма, магазин) подсвечиваются для проверки. ИНН больше не используется.
- **iPhone:** вкладки «Главная · Покупки · Чеки · Отчёты · Настройки», сканер документов (VisionKit), камера, галерея, файлы,
  поиск и фильтры (даты, сцены, категории, наличие чека).
- **Mac:** слева проекты, по центру таблица расходов (сортировка, выбор нескольких строк), справа карточка и крупное фото чека,
  сверху показатели. Перетаскивание фото из Finder (сразу много), массовое редактирование, просмотр с увеличением, сохранение
  Excel/PDF через Finder, печать PDF. Сочетания клавиш: ⌘N новая покупка, ⌘I загрузить чеки, ⌘E Excel, ⇧⌘E PDF, ⌘P печать,
  ⌘Y увеличить фото, ⇧⌘B изменить выбранные, ⌘⌥F фильтры, ⌘M выдача денег, ⌘, настройки проекта, ⌫ удалить.
- **Excel (.xlsx)**: листы «Сводный отчёт», «Детализация расходов» (фото чека в строке покупки), «Реестр чеков», «Фотографии чеков».
  Изображения физически лежат внутри файла (`xl/media`), пропорции сохранены, строки подогнаны под высоту фото. Файл собирается
  собственным писателем без сторонних библиотек.
- **Синхронизация iCloud (CloudKit)**: общая модель данных Core Data для обеих платформ. Если iCloud недоступен — всё работает
  локально, изменения уходят при появлении сети. Дубли категорий и повторяющиеся номера чеков после синхронизации исправляются сами;
  при одновременной правке одного поля побеждает последнее изменение.
- **Резервные копии:** раз в сутки автоматически (последние 7) — ZIP с данными и оригиналами фото; восстановление ничего не затирает.

## Как собрать и запустить (Xcode 15.2+, macOS Ventura подходит)

1. Откройте `Rekvizit.xcodeproj` (он лежит в репозитории; пересоздаётся командой `xcodegen generate` из `project.yml`).
2. В Xcode: цель **Rekvizit-iOS** (или **Rekvizit-macOS**) → Signing & Capabilities → выберите свою Team. При необходимости смените
   Bundle Identifier (`ru.desingerkino.rekvizit`) и контейнер iCloud (`iCloud.ru.desingerkino.rekvizit`) на свои.
3. **Бесплатный Apple ID:** выберите схему **Rekvizit-iOS-Local** / **Rekvizit-macOS-Local** — сборка без iCloud, всё остальное работает.
4. **Платный Apple Developer Program:** обычные схемы **Rekvizit-iOS** / **Rekvizit-macOS** — с iCloud-синхронизацией. На обоих устройствах
   должен быть выполнен вход в один и тот же Apple ID.
5. Подключите iPhone, нажмите ▶︎ (на iPhone включите режим разработчика: Настройки → Конфиденциальность и безопасность).

Готовая сборка для Mac **без подписи Apple и без iCloud**: https://github.com/desingerkino/Otchetkino/releases/tag/latest
(при первом запуске: правый клик → «Открыть»). Там же образцы отчётов `sample-report.xlsx` и `sample-report.pdf`.

## Версия 2.0: что изменилось

### Архитектура
SwiftUI + Core Data (модель собирается в коде, `Model.swift`), общая для iPhone и Mac. Слои: `Data` (модель, домен, хранилище),
`Services` (сохранение, распознавание, отчёты, справочник магазинов), `Views` (общие экраны), `macOS` (рабочее место Mac).
Проект генерируется XcodeGen из `project.yml`.

### Автосохранение и кнопка «Сохранить»
- Любое изменение (текст, суммы, магазин, фото, позиции, сцены) сохраняется само через ~0,8 с после паузы (`SaveCoordinator`).
- Принудительное сохранение при смене проекта и экрана, уходе в фон, закрытии окна и выходе из приложения.
- Ошибка записи не откатывает данные: показывается статус «Ошибка сохранения», попытки повторяются.
- Кнопка «Сохранить» (⌘S) с состояниями: «Сохранено» / «Не сохранено» / «Сохраняется…» / «Ошибка».
- Текстовые поля держат локальное состояние и фиксируют его в базе после паузы, при потере фокуса и закрытии — поэтому отмена работает крупными шагами.
- Черновиков больше нет: чек сразу обычный. Пустые чеки (без фото, магазина, комментария и данных позиций) удаляются сами.

### Справочник магазинов
Подсказки при вводе, регистр и «ё/е» не различаются, новый магазин попадает в справочник сам. В настройках («Магазины»):
переименование, объединение, удаление, счётчик чеков; переименование и объединение обновляют все чеки.

### Деньги
Поля сумм — с разделителями тысяч при вводе (`1 234,56`), хранение в копейках.

### Распознавание
Выбирается лучший из вариантов обработки изображения; «К ОПЛАТЕ» и «ИТОГО» приоритетнее промежуточных строк (подытог, скидка, НДС,
наличные, сдача); даты в форматах `дд.мм.гггг`, `дд/мм/гг`, `гггг-мм-дд`, «8 ноября 2026», исправление O→0; срок годности и будущие даты не принимаются.
Ничего не выдумывается: если не нашлось — поле пустое.

### PDF
Секции 1–4, нумерация страниц «N из M», без ИНН.

### Отмена / повтор
⌘Z / ⇧⌘Z (на Mac), до 60 уровней, включая фото и позиции; внутри текстового поля действует отмена самого поля.

### Группировка по датам
Таблица расходов на Mac разбита на дни с заголовками и подытогом за день.

### Изменения базы данных
- Новая сущность `RStore` (справочник магазинов). Миграция лёгкая, автоматическая.
- Атрибут `isDraft` оставлен для совместимости схемы, не используется. При первом запуске бывшие черновики становятся обычными
  чеками (**и теперь входят в итоги**), перед этим делается резервная копия.
- **CloudKit:** после выхода в TestFlight/релиз схему с новой сущностью нужно развернуть в Production в CloudKit Dashboard
  («Deploy Schema Changes»).

### Windows
Пункты про Windows, Ctrl+Z и EXE не применимы: приложение нативное для Apple (iPhone и Mac). Аналог Ctrl+Z на Mac — ⌘Z.

## Честные ограничения

- iCloud-синхронизацию нельзя проверить без подписанной сборки и двух устройств — она настроена по правилам CloudKit, но «вживую» не прогонялась.
- Камера и сканер документов в симуляторе недоступны; интерфейс проверен сборкой и запуском, но не ручным прохождением на устройстве.
- Качество распознавания зависит от фото. Проверено на отрисованном чеке; на живых термочеках возможны ошибки — поэтому всегда есть проверка.
- Фото в Excel/PDF вставляются как JPEG с длинной стороной до 3200 px (иначе файл вырастает до сотен МБ). Оригиналы в приложении не меняются.
- Excel проверен через openpyxl и LibreOffice; в самом Microsoft Excel и Numbers файл не открывался.
