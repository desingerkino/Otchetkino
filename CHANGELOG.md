# Журнал изменений

## 2.0

### Добавлено
- Автосохранение всех изменений, кнопка «Сохранить» (⌘S) со статусами, защита при закрытии/смене проекта/уходе в фон.
- Справочник магазинов (`RStore`): подсказки, объединение, переименование, удаление, управление в настройках.
- Отмена и повтор (⌘Z / ⇧⌘Z), до 60 уровней, с фото и позициями.
- Группировка расходов по дням (Mac).
- Поля сумм с разделителями тысяч; предобработка фото для распознавания; флаги низкой уверенности (дата, сумма, магазин).
- Новое оформление (палитра, карточки, кнопки).
- Тесты: автосохранение, undo/redo, магазины, PDF, качество распознавания (38 тестов всего).

### Изменено
- Чеки больше не бывают черновиками; бывшие черновики конвертируются при запуске (с резервной копией) и учитываются в итогах.
- Определение итога: приоритет «К ОПЛАТЕ»/«ИТОГО», игнор подытога, скидки, НДС, сдачи.
- Определение даты: больше форматов, отсев срока годности и будущих дат.
- PDF: секции 1–4, нумерация страниц «N из M».
- CI: раннер `macos-15`, сборка на каждый push и pull request.

### Таблица покупок (Mac)
- Заголовки дней без сумм; чередование строк (#FFFFFF / #F2F3F5) внутри каждой группы; выбранная строка — синий фон и белый текст.
- CI: DMG для Mac, файлы в артефакте лежат в корне архива.

### Удалено
- ИНН из формы, распознавания, PDF и Excel.
- Режим «черновик» (атрибут `isDraft` оставлен в схеме для совместимости).

### Исправлено
- Сумма вида «ИТОГО 1120 00» подменялась датой следующей строки.
- Потеря введённых данных при закрытии окна и смене проекта.

### Примечания
- CloudKit: развернуть схему с `RStore` в Production.
- Пункты про Windows/EXE/Ctrl+Z неприменимы: приложение нативное Apple.

## 2.1 (интерфейс)
- Кнопка «+ Добавить» справа от «Фильтры» (тот же `addManual()`, что у «+» и ⌘N, без дубликатов).
- Карточка покупки: номер чека слева, редактируемое поле даты справа в одной строке; общая высота и центровка по вертикали (раньше колонки с подписями разной высоты были выровнены по верху).
- Ненавязчивая подсветка строки таблицы при наведении.
- Карточка покупки: форма («Чек», позиции, сумма) теперь сверху, блок «Фотографии чека» — ниже; компоненты и обработчики те же, поменялся только порядок.
